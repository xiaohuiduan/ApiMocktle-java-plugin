ApiMocktle

Extract APIs from source code and sync them to ApiMocktle

  • Parse API documentation from Javadoc, KDoc and ScalaDoc
  • Supports Spring MVC and Feign clients
  • Supports javax.validation, Jackson, Gson and Swagger annotations
  • Flexible configuration rules with minimal code intrusion

Usage

  1. Right-click a controller file, class or method in the editor or Project view
  2. Choose Export to ApiMocktle from the context menu
  3. APIs are synced to ApiMocktle automatically
